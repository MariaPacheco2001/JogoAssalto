# GC-028 Implementar caixas móveis com limites físicos

[Issue #28](https://github.com/mjpacheco2001/golpe-calculado/issues/28) · Marco 3 · P1

## Objetivo

Permitir mover objetos para abrir acessos ou alterar cobertura.

## Situação de referência

Registo de 9 de outubro de 2026. Issue aberta no momento da preparação deste plano.

Caixa com Rigidbody e interação de empurrar; física e bloqueios ainda requerem teste manual.

Este commit acrescenta documentação de validação. Os passos abaixo ainda não foram executados como sessão manual; as caixas registam a próxima execução, não substituem o estado da issue.

## Preparação

Usar Unity 6000.6.5f1 e a cena M02_AssaltoArmazem, ou a build correspondente quando o caso exigir Windows. Registar o commit e a versão antes de começar. Nos testes de persistência e falhas, usar cópias dos dados de teste; preservar a partida pessoal.

Dependências: [#25](https://github.com/mjpacheco2001/golpe-calculado/issues/25).

## Procedimento

1. Empurrar uma caixa contra parede e junto de uma porta.
2. Tentar usá-la como cobertura.
3. Deslocá-la até uma passagem e verificar se existe recuperação.

## Resultado esperado

Física respeita obstáculos e o jogador não bloqueia a missão de forma irreversível.

## Critérios a verificar

- [ ] Caixas movem-se de forma controlada.
- [ ] Colisões respeitam paredes e portas.
- [ ] Não bloqueiam irremediavelmente a missão.
- [ ] Feedback distingue objeto móvel.
