Usar Unity 6000.6.5f1 e a cena M02_AssaltoArmazem, ou a build correspondente quando o caso exigir Windows. Registar o commit e a versão antes de começar. Nos testes de persistência e falhas, usar cópias dos dados de teste; preservar a partida pessoal.

Dependências: [#53](https://github.com/mjpacheco2001/golpe-calculado/issues/53), [#35](https://github.com/mjpacheco2001/golpe-calculado/issues/35), [#23](https://github.com/mjpacheco2001/golpe-calculado/issues/23).

1. Abrir o diário numa partida nova.
2. Ler um documento e experimentar um circuito.
3. Restaurar um checkpoint anterior e depois reabrir o jogo.
